This is a space shooter for Lancerhacks 2026
The spaceship shoots by clicking the left mouse button and moves left to right by with the arrow keys or A/D keys.
Enemies sometimes drop level-ups (temporary weapon enhancement, shield) and can be picked up.
The songs we used are copyrighted so the menu and game music can be swapped out for other music.
To run, Python3 and Pygame need to be installed, and all image and sound files need to be kept in the same folder as the code.
